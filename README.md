
# SQL Practice

This repository contains my SQL practice while preparing for coding assessments and technical interviews.

## Contents

* SQL practice problems organized by topic
* Query solutions with explanations
* Cheat sheets for quick revision
* Common interview patterns and mistakes

## Topics Covered

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* JOINS
* SELF JOIN
* SUBQUERIES
* CASE Expressions
* Common Table Expressions (CTEs)
* Window Functions

## Repository Structure

Each topic has a dedicated SQL file containing multiple practice problems and solutions. Cheat sheets are maintained separately for quick revision and concept review.

## Purpose

The goal of this repository is to track progress, strengthen SQL problem-solving skills, and build a revision resource for future coding assessments and interviews.
